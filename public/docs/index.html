HubSpot Productboard Integration v1.0

Keep your Productboard account data in sync with HubSpot — automatically surface customer segments, deal values, and account details without leaving your product tool.

Overview

This integration pulls company data from HubSpot and pushes it into Productboard so your product teams always have accurate customer context when triaging feedback and planning roadmaps.

What gets synced

HubSpot objectProductboard objectDirection
CompanyCompanyHubSpot → Productboard
Company propertiesCustom fieldsHubSpot → Productboard (configurable)
ℹ
One-way sync Data flows from HubSpot into Productboard only. Changes made to companies inside Productboard are not written back to HubSpot.

Key behaviours

  • Idempotent: Running the same sync twice never creates duplicates. The engine matches on HubSpot company ID.
  • Incremental: Only records that have changed since the last successful sync are re-processed by default.
  • Dry-run safe: Set DRY_RUN=true in the environment to preview all writes without touching any API.
  • Rate-limit aware: A token-bucket limiter automatically throttles requests to stay inside Productboard (300 req/min) and HubSpot (100 req/10 s) limits.

Setup walkthrough

Getting from zero to your first sync takes about five minutes.

1
Sign in Open the app and click Sign in with Google. Use your company Google Workspace account — personal Gmail addresses are not permitted.
2
Connect Productboard Go to the Connect tab. Paste your Productboard API key and click Verify. The app will confirm your workspace name.
3
Connect HubSpot Still on the Connect tab, paste your HubSpot service key token and click Verify. The portal ID and account name will appear when the token is valid.
4
Filter which accounts to sync (optional) Open Filter accounts to narrow down which HubSpot companies are included. You can filter by property value, lifecycle stage, owner, or any HubSpot company property. Skip this step to sync all companies.
5
Map fields Open Map fields to choose which HubSpot company properties map to which Productboard company fields. At minimum, map Company name. Unmapped properties are ignored.
6
Schedule or run manually Open Schedule to set up automatic syncs (daily, hourly, etc.), or click Sync now on the same tab for a one-time run. Watch live progress in the status panel.

Connect accounts

Productboard API key

To generate a Productboard API key:

  1. In Productboard, go to Settings → API & integrations → API keys.
  2. Click Generate new key. Give it a descriptive name like HubSpot sync.
  3. Copy the key immediately — it is shown only once.
ℹ
The Productboard API key is scoped to the user who generated it. If that user is deactivated, the key stops working. Use a service account if your organisation has one.

HubSpot service key token

To create a HubSpot service key (requires Super Admin or Developer tools permission):

  1. In HubSpot, go to Development → Keys → Service Keys and click Create service key.
  2. Name it (e.g., pb-hubspot-sync).
  3. Click Add new scope and enable all three: crm.objects.companies.read, crm.schemas.companies.read, and crm.objects.owners.read (the last one is needed to resolve HubSpot owner IDs to emails when mapping to Productboard member fields).
  4. Click Create and confirm, then copy the generated token.

Filter accounts

By default the sync processes every company in your HubSpot portal. Use filters to limit scope — useful for large portals or when you only want to sync a specific customer segment (e.g., only Enterprise accounts with an active deal).

Filter types

Filter typeExample use
Property equalsLifecycle stage = customer
Property containsIndustry contains Software
Property is known / unknownAnnual revenue is known
Property greater / less thanNumber of employees > 50

Multiple filters are combined with AND — a company must match all active filters to be included.

ℹ
Preview before syncing After setting filters, click Preview to see a count of matching companies before committing to a full sync.

Map fields

Field mapping controls which HubSpot company properties are written into which Productboard fields. Any HubSpot property that exists in your portal can be mapped.

Built-in mappings

HubSpot propertyProductboard fieldNotes
nameCompany nameRequired. Used as the display name in Productboard.
domainDomainAlso used for deduplication matching.
hs_object_idExternal IDAlways synced automatically — do not remove.

Custom field mappings

Any HubSpot company property can be mapped to a Productboard custom field. The Map fields tab shows all available HubSpot properties on the left and all configured Productboard custom fields on the right. Drag a line between them (or use the dropdowns) to create a mapping.

⚠

Schedule syncs

Scheduled syncs run automatically in the background using Google Cloud Scheduler. You do not need to keep the browser open.

ℹ
Scheduled syncs run in UTC. If you set "Daily at midnight", that's 00:00 UTC — adjust for your timezone.

Manual sync

To run a one-off sync at any time, go to the Schedule tab and click Sync now. A live progress feed shows created, updated, and error counts per batch.

Sync history

The History tab shows a log of every sync run, including start time, duration, outcome, and record-level stats.

ColumnMeaning

Rate limits

APILimitHow we handle it
Productboard 300 requests / minute Token-bucket limiter — requests queue automatically when approaching the ceiling.
HubSpot (free) 100 requests / 10 s Same token-bucket, tuned to the free tier limit. Set your tier in Settings.
HubSpot (paid) 150 requests / 10 s Configure your HubSpot tier in Settings → Advanced to use the higher limit.

If a sync run errors with 429 Too Many Requests, the engine backs off with exponential backoff and retries automatically. You should not need to intervene.

Troubleshooting

Authentication errors

ErrorLikely causeFix
401 Unauthorized (Productboard) API key is invalid or was rotated. Re-paste your Productboard API key in the Connect tab and click Verify.
401 Unauthorized (HubSpot) Service key token rotated, deleted, or scopes changed. Generate a new service key in HubSpot under Development → Keys → Service Keys and re-enter it in the Connect tab.
Sign-in blocked Your Google account is not on the allowed domain. Use your @yourcompany.com Google Workspace account.

Sync errors

ErrorLikely causeFix
Company not appearing in Productboard Company was filtered out, or the sync hasn't run yet. Check your filter rules in Filter accounts. Run a manual sync from Schedule.
Custom field value not syncing Field not mapped, or the Productboard custom field doesn't exist. Verify the mapping in Map fields. Confirm the custom field exists in Productboard settings.
429 Too Many Requests Rate limit hit — usually only on very large portals. The engine retries automatically. If it persists, reduce SYNC_CONCURRENCY in Settings → Advanced.
Partial sync — some records failed Individual company records contain unexpected field values. Download the history CSV from the History tab and review the error column for specific record IDs.

Scheduled sync not running

  1. Confirm the schedule is active in the Schedule tab (the toggle should be on).
  2. Check the History tab for the expected run time — Cloud Scheduler may have a few minutes of jitter.
  3. If no entry appears after 15 minutes past the scheduled time, check the Cloud Scheduler console in GCP for error logs.

FAQ

Can I sync data the other way — from Productboard back to HubSpot?

Not currently. The integration is HubSpot → Productboard only. Reverse sync (e.g., writing Productboard feature votes back to HubSpot deals) is on the roadmap.

Will the sync overwrite data I've manually entered in Productboard?

Yes, for any field that has an active mapping. If you map HubSpot's Industry to a Productboard custom field, any manual edits to that field in Productboard will be overwritten on the next sync. Only map fields where HubSpot is the system of record.

How are duplicate companies handled?

The engine matches on HubSpot company ID (hs_object_id). If a Productboard company already has this external ID set, it is updated rather than re-created. If two HubSpot companies share a domain, they are both synced as separate Productboard companies.

What happens if I delete a company in HubSpot?

Deleted HubSpot companies are not automatically removed from Productboard. The integration only creates and updates — it does not delete. You'll need to archive the company manually in Productboard.

Can I run this locally without a GCP project?

Yes. Set FIRESTORE_EMULATOR_HOST=127.0.0.1:8080 and FIRESTORE_PROJECT_ID=demo-local in your .env file, then run npm run dev. Scheduled syncs require Cloud Scheduler and won't work locally, but you can trigger syncs manually from the UI.

How do I grant another team member access?

Access is controlled by Google OAuth — any user in your allowed Google Workspace domain can sign in. To restrict to specific addresses, set GOOGLE_ALLOWED_EMAILS in your environment. Ask your infrastructure team to update the environment variable and redeploy.

Where are my API keys stored?

API keys are encrypted and stored in Google Cloud Secret Manager in production. They are never written to the database or logs. In local development, they are stored in Firestore emulator state (not uploaded anywhere).
